# 📊 Digital Marketing Performance Dashboard

## 📌 Project Overview

The **Digital Marketing Performance Dashboard** is an Excel-based analytics project developed to evaluate the performance of digital marketing campaigns. The project analyzes campaign data across different marketing channels, regions, and time periods to measure business performance using key performance indicators (KPIs) and interactive visualizations.

This dashboard enables users to monitor marketing effectiveness, identify high-performing campaigns, and make data-driven decisions.

---

## 🎯 Project Objectives

- Analyze digital marketing campaign performance.
- Clean and transform raw marketing data.
- Calculate important marketing KPIs.
- Build interactive Pivot Tables and Pivot Charts.
- Create an interactive dashboard using Excel.
- Provide actionable business insights and recommendations.

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Conditional Formatting

---

## 📂 Dataset Information

The dataset contains digital marketing campaign information, including:

- Campaign ID
- Date
- Marketing Channel
- Region
- Budget
- Spend
- Impressions
- Clicks
- Conversions
- Revenue

---

## 🧹 Data Preprocessing

The following data cleaning and transformation steps were performed:

- Removed duplicate records
- Checked for missing values
- Verified data types and formats
- Created a **Year-Month** column
- Calculated:
  - CTR (Click Through Rate)
  - CPC (Cost Per Click)
  - CPA (Cost Per Acquisition)
  - ROAS (Return on Ad Spend)
  - Profit
  - Profit Margin

---

## 📊 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

- Total Marketing Spend
- Total Revenue
- Total Profit
- Average ROAS

---

## 📈 Dashboard Features

The dashboard contains:

- Monthly Spend vs Revenue Trend
- Average ROAS by Marketing Channel
- Region-wise Conversions
- Budget Allocation by Channel
- Marketing Funnel (Impressions → Clicks → Conversions)
- Interactive Slicers
  - Marketing Channel
  - Region
  - Year-Month

---

## 📌 Key Insights

- Revenue exceeded total marketing spend, indicating profitable campaigns.
- Average ROAS remained above 2, showing effective advertising performance.
- Marketing performance varied across channels and regions.
- Campaign performance changed over different months.
- The marketing funnel highlighted customer drop-offs from impressions to conversions.

---

## 💡 Recommendations

- Increase investment in high-performing marketing channels.
- Optimize campaigns with lower ROAS.
- Focus on high-converting regions.
- Improve ad creatives to increase CTR.
- Optimize landing pages to improve conversion rates.
- Monitor KPIs regularly for continuous campaign improvement.
